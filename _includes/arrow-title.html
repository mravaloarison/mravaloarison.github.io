{%- comment -%} A list title followed by a small ↗ that marks the row as a link (project lists and post lists), like brittanychiang.com. The last word and the arrow are kept together, so the arrow never wraps onto a line by itself. On hover it nudges up and right. Param: text (the title). {%- endcomment -%} {%- assign words = include.text | split: " " -%} {%- assign last_word = words | last -%} {%- assign lead_count = words | size | minus: 1 -%} {%- if lead_count > 0 -%}{{ words | slice: 0, lead_count | join: " " }} {% endif -%} {{ last_word }}
