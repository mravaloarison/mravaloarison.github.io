{%- comment -%} A list title followed by Google's 🔗 (Noto Emoji artwork, assets/emoji/link.svg), which marks the row as a link (project lists and post lists). The last word and the emoji are kept together, so the emoji never wraps onto a line by itself. On hover it nudges up and right. alt="" because it's decoration: the title is the link text.
